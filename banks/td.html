Convert TD CSV to QBO / QFX / OFX

Two TD commercial guides describe spreadsheet downloads, and neither describes a QuickBooks Web Connect or Quicken Web Connect file. Personal EasyWeb is not covered here, because these guides are for TD Business Central and TD eTreasury.

Convert your file now: open the converter. It runs in your browser, your statement is never uploaded, and it's free up to 30 transactions per file.

TD Business Central

The TD Business Central customer portal user guide says that from a desktop or mobile device you can export deposit and loan account activity as a CSV file with the export button. Only the transactions you are viewing on screen are exported. Deposit account statements on the Statements tab can be viewed for cycle dates up to 7 years back. Exporting the on-screen list is separate from opening a statement.

TD eTreasury Quick Download

Download account activity says Quick Download on the Account Activity page saves a .CVS file (TD's spelling). The format cannot be changed.

  1. On the main menu, select Accounts, then under Manage Accounts select Account Activity.
  2. Select Quick Download.
  3. Select Submit.
  4. Open the file or save it. The default format is .CVS.

The first Quick Download includes transactions up to a maximum number of days set by a system administrator. TD's example is 120 days. Later Quick Downloads include only transactions since the previous download. If the number of transactions is over the limit, the file stops at that limit. A .CVS file is a comma-separated file under a different extension. You can rename a copy to .csv or drop the file on the converter if your browser saved it as text.

CSV columns

The source linked below does not publish the column headings in the file. After you download it, use the header row you actually see. In the converter, map a date, a description, and either one signed amount or separate money-in and money-out columns. The preview rewrites dates as YYYY-MM-DD so you can confirm the day and the month before you download.

Convert it

  1. Open the converter and drop in the CSV or Excel file. Excel (.xlsx or .xls) is fine.
  2. If the bank put your name or account number above the table, set the header row to the row that names the columns.
  3. Map the date, the description, and either one signed amount or separate paid-in and paid-out columns. Confirm the dates in the preview, which shows them as YYYY-MM-DD.
  4. Choose QBO for QuickBooks Desktop, QFX for Quicken, or OFX, and download.

Import the converted file

  • QuickBooks Online
  • QuickBooks Desktop (needs a .qbo file)
  • Quicken for Windows or Mac (needs a .qfx file)

FAQ

What is a .CVS file?

TD eTreasury's help says the Quick Download format is .CVS and cannot be changed. Treat it as a comma-separated spreadsheet. It is not a .qbo or .qfx file.

The second download is missing older rows.

TD says a later Quick Download only contains transactions since the prior download. The first download is the one that goes back to the administrator's day limit.

Business Central only exported one page.

The user guide says the CSV contains only the activity you are viewing. Change the on-screen filter, then export again.
