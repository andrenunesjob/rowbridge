Convert ANZ CSV to QBO / QFX / OFX

ANZ documents an export of transactions from the last 2 years, and only for open accounts. The help page tells you to pick a software package. It also says a CSV file can be opened in a plain text editor if you do not have spreadsheet or accounting software. It does not list every package in the dropdown, so this page does not claim that QBO or QFX is missing from that list.

Convert your file now: open the converter. It runs in your browser, your statement is never uploaded, and it's free up to 30 transactions per file.

Export from Internet Banking

Access your account statements and notices says, for open accounts:

  1. Log in to ANZ Internet Banking.
  2. Select the account on the homepage.
  3. Select Download at the top of the Transactions tab.
  4. Select the time period.
  5. Select a software package from the dropdown.
  6. Select Download.

If you need a file you can convert, choose the CSV option ANZ describes for people without accounting software, when that option is in the dropdown. The 2-year export on that page is for open accounts. ANZ's notes on the same page say online statements are not the same thing as the transaction history.

CSV columns

The source linked below does not publish the column headings in the file. After you download it, use the header row you actually see. In the converter, map a date, a description, and either one signed amount or separate money-in and money-out columns. The preview rewrites dates as YYYY-MM-DD so you can confirm the day and the month before you download.

Convert it

  1. Open the converter and drop in the CSV or Excel file. Excel (.xlsx or .xls) is fine.
  2. If the bank put your name or account number above the table, set the header row to the row that names the columns.
  3. Map the date, the description, and either one signed amount or separate paid-in and paid-out columns. Confirm the dates in the preview, which shows them as YYYY-MM-DD.
  4. Choose QBO for QuickBooks Desktop, QFX for Quicken, or OFX, and download.

Import the converted file

  • QuickBooks Online
  • QuickBooks Desktop (needs a .qbo file)
  • Quicken for Windows or Mac (needs a .qfx file)

FAQ

The account is closed.

ANZ labels the 2-year export as only available for open accounts. This page does not describe a different export for closed accounts.

Which software package should I pick?

ANZ does not publish the full list on the help page. CSV is the format they mention for opening in a text editor, and it is the one to convert to QBO or QFX.

Can I use the PDF statement?

ANZ's PDF statements are a separate download. Rowbridge does not read them. Use the transaction export.
