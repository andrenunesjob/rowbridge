Convert Ally Bank CSV to QBO / QFX / OFX

Ally Bank's help page says you can download account activity as a comma-separated (CSV) file or a Quicken (QFX) file. It does not mention a QuickBooks Web Connect (.qbo) file. QuickBooks Desktop's Web Connect import only reads .qbo, so a CSV converted to QBO is the route when the QFX file is the wrong format for QuickBooks.

Convert your file now: open the converter. It runs in your browser, your statement is never uploaded, and it's free up to 30 transactions per file.

Download the CSV

Ally's account-information FAQ says:

  1. Log in and select the account.
  2. Scroll to Transactions History.
  3. Select the download icon.
  4. Save a CSV file or a Quicken QFX file.

The same page says you can see up to 18 months of account activity, and that you can download activity to Quicken. If every Ally Bank account is closed, Ally says you can access account information online for 60 days, and still view statements and tax forms for the last 7 years. The download steps above are for an open account's transaction history, not a promise that a closed account offers the same CSV.

Ally also says it does not currently offer business banking products. This page is about Ally Bank deposit accounts.

CSV columns

The source linked below does not publish the column headings in the file. After you download it, use the header row you actually see. In the converter, map a date, a description, and either one signed amount or separate money-in and money-out columns. The preview rewrites dates as YYYY-MM-DD so you can confirm the day and the month before you download.

Convert it

  1. Open the converter and drop in the CSV or Excel file. Excel (.xlsx or .xls) is fine.
  2. If the bank put your name or account number above the table, set the header row to the row that names the columns.
  3. Map the date, the description, and either one signed amount or separate paid-in and paid-out columns. Confirm the dates in the preview, which shows them as YYYY-MM-DD.
  4. Choose QBO for QuickBooks Desktop, QFX for Quicken, or OFX, and download.

Import the converted file

  • QuickBooks Online
  • QuickBooks Desktop (needs a .qbo file)
  • Quicken for Windows or Mac (needs a .qfx file)

FAQ

Does Ally offer a QBO download?

Ally's FAQ names CSV and Quicken QFX only. It does not name QBO. Use the CSV with the converter if QuickBooks Desktop is what you need.

How far back does the download go?

Ally says you can see up to 18 months of account activity. The FAQ does not spell out a separate limit for the file itself.

I already downloaded a QFX file and Quicken rejected it.

Download the CSV from the same screen and convert that to QFX. See Quicken error CC-885 if Web Connect for the institution has stopped.
