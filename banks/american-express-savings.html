Convert American Express Savings CSV to QBO / QFX / OFX

American Express Savings says it does not let sites like Quicken log in on behalf of customers. You download a file yourself and import it. Card accounts are a different download: see American Express cards.

Convert your file now: open the converter. It runs in your browser, your statement is never uploaded, and it's free up to 30 transactions per file.

Download transactions

Amex's savings FAQ lists these steps:

  1. Log in to your American Express Savings account.
  2. Select the Documents tab at the top of the page.
  3. Select Download Transactions, towards the top right.
  4. Select the account.
  5. Select the start date, end date, and file type.
  6. Select Download.

The FAQ tells you to choose a file type. It does not name CSV, QFX, QBO, or any other extension. If the file you receive is a spreadsheet, convert that. If Quicken will not import the file the bank labeled for Quicken, download again and pick the spreadsheet type if it is offered on that screen. Do not guess a menu that is not on the page.

CSV columns

The source linked below does not publish the column headings in the file. After you download it, use the header row you actually see. In the converter, map a date, a description, and either one signed amount or separate money-in and money-out columns. The preview rewrites dates as YYYY-MM-DD so you can confirm the day and the month before you download.

Convert it

  1. Open the converter and drop in the CSV or Excel file. Excel (.xlsx or .xls) is fine.
  2. If the bank put your name or account number above the table, set the header row to the row that names the columns.
  3. Map the date, the description, and either one signed amount or separate paid-in and paid-out columns. Confirm the dates in the preview, which shows them as YYYY-MM-DD.
  4. Choose QBO for QuickBooks Desktop, QFX for Quicken, or OFX, and download.

Import the converted file

  • QuickBooks Online
  • QuickBooks Desktop (needs a .qbo file)
  • Quicken for Windows or Mac (needs a .qfx file)

FAQ

Can Quicken connect to American Express Savings?

Amex says Savings does not allow sites like Quicken to log in for you. The documented path is the download on the Documents tab.

Which file type should I pick?

The help article does not list them. Pick the type on the screen. Use the converter when the result is CSV or Excel.

Is this the same as an American Express card?

No. Card downloads are described on Amex's card help pages and on the card page.
