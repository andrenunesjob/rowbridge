# Rowbridge

Rowbridge converts bank CSV and Excel exports into QBO (QuickBooks Web Connect), QFX (Quicken), and OFX files. The converter runs in the browser.

This repository is a static site (plain HTML, CSS, and vanilla JavaScript) served by GitHub Pages from the repository root:

https://andrenunesjob.github.io/rowbridge/

Statement files are read and converted on your computer. They never leave the browser and are never uploaded.

`.nojekyll` is committed so Pages serves these files as they are.
