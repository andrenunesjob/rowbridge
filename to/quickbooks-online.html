Import a QBO, QFX, or CSV file into QuickBooks Online

Intuit's article Manually upload transactions into QuickBooks Online (updated 24 August 2026) is the source for the steps below. Use it when QuickBooks cannot connect to the bank, or when you need transactions from before the connection started.

Convert your file now: open the converter. It runs in your browser, your statement is never uploaded, and it's free up to 30 transactions per file.

What Intuit accepts

For a transaction list, Intuit says the file must be in English and 350 KB or less. They suggest a QuickBooks Online data (QBO) file. You can also upload a Quicken QFX file or a CSV. A separate set of steps on the same page covers .csv, .txt, .qbo, and .ofx, up to 1,000 lines, one transaction per line.

A CSV needs either 3 columns (Date, Description, Amount) or 4 columns (Date, Description, Credit, Debit). Intuit also says:

  • Remove the word "amount" from Credit and Debit headers.
  • Leave Amount, Credit, or Debit cells that contain only zero blank.
  • Remove numbers from cells in the Description column.
  • Use one date format in the whole file. Intuit recommends dd/mm/yyyy.
  • If the date cell also contains a weekday (their example is "20/11/2022 TUE"), split that into its own column.
  • For a large file, shorten the date range and upload in batches.

Bank exports often fail those rules. Converting the CSV or Excel file to QBO first avoids remaking the spreadsheet by hand. QuickBooks Desktop cannot use this same upload screen. It needs a .qbo Web Connect file.

Upload the file

  1. Go to All apps, then Accounting, then Bank transactions.
  2. If you see a tile for the account, select it.
  3. Select the Link account dropdown, then Upload from file. If the account is not connected yet, Intuit also shows Upload from file or "Or upload transactions manually".
  4. Select the file and Continue.
  5. Choose the QuickBooks account. If you do not have one yet, use Add New.
  6. Continue, match the columns if the file is a CSV, then Continue.
  7. Select the transactions to import, Continue, then Yes, then Done.

Intuit says to start the file at least one day before the oldest transaction already in that QuickBooks account, and to check the chart of accounts first so you do not create duplicates. Their article also says an account that is already connected downloads transactions up to a certain date. Upload only the gap you are missing.

The same article describes uploading a PDF or image of a statement. Rowbridge does not read PDFs. Download CSV or Excel from the bank and convert that.

FAQ

Should I upload the bank's CSV or a QBO file?

Intuit accepts both. They suggest QBO. A CSV has to match the 3-column or 4-column layout and the date rules above. A QBO file skips that cleanup.

The dates landed in the wrong month.

Intuit recommends dd/mm/yyyy in that article. A US company file may still expect month-first dates. In the converter, pick the date order that matches the bank file. The preview shows YYYY-MM-DD.

Charges came in as deposits.

On the upload screen Intuit describes, if amounts are reversed you can reverse all values. You can also tick Flip signs in the converter before you download.
