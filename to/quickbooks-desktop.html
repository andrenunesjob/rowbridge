Import a QBO file into QuickBooks Desktop

QuickBooks Desktop does not import a bank CSV. Intuit's article Download bank feed transactions in QuickBooks Desktop says Web Connect only works with .qbo files. QFX and QIF Quicken files will not work.

Convert your file now: open the converter. It runs in your browser, your statement is never uploaded, and it's free up to 30 transactions per file.

Before you import

From that article, and from Import and export data in QuickBooks Desktop:

  • Set up the account for bank feeds before you download, if you are using bank feeds.
  • Back up the company file. Intuit says you cannot undo an import.
  • Importing a Web Connect file requires you to be signed in to your Intuit account inside QuickBooks Desktop.
  • Intuit says you can't download transactions into the same company file more than once, and that the bank may have to reopen them. A file you build yourself from a CSV is a different path from the bank's own Web Connect download. Still back up first.

Import the .qbo file

An Intuit reply on Downloading bank transactions gives this menu path after you have the .qbo file:

  1. From the Banking menu, select Bank Feeds, then Import Web Connect Files.
  2. Select the QBO file, then Open.
  3. Choose the bank account.
  4. Select Continue, then OK.
  5. Go to the Bank Feeds Center to review the transactions.

If import asks you to sign in, use the Intuit account inside QuickBooks. Intuit's Fix Web Connect import errors article says that if you use Advanced Mode you may need to sign in or switch modes, and that you can switch to Classic mode (Register mode) from Banking, Bank Feeds, Change Bank Feeds Mode, then import the .qbo file again.

QuickBooks Online uses a different screen. See upload a file in QuickBooks Online. Quicken needs a .qfx file, not this .qbo file: import into Quicken.

FAQ

Can I rename a QFX or CSV to .qbo?

No. Intuit says Web Connect only reads .qbo files, and that QFX and QIF will not work. Convert the spreadsheet to a real .qbo file.

QuickBooks says it cannot verify the financial institution.

That check is on the bank id inside the .qbo file. The CSV to QBO guide explains the id the converter writes and what to try if your version rejects it.

The account is already connected to a bank feed.

Importing on top of a live feed can duplicate transactions. Deactivate the feed for that account, or import into a date range the feed does not cover, and back up first.
