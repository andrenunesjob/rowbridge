Import a QFX file into Quicken

Quicken's Web Connect import reads a .qfx file, not a bank CSV. These steps are from Quicken's help, not from a bank.

Convert your file now: open the converter. It runs in your browser, your statement is never uploaded, and it's free up to 30 transactions per file.

Quicken for Windows

How do I update my spending accounts? says:

  1. Back up the Quicken data file first. Quicken's Importing files from your bank article says to back up before a QFX import.
  2. Choose File menu, then File Import, then Web Connect File.
  3. Select the .qfx file and select OK.
  4. If you already have the account, choose Link and select that account. Otherwise name the new account.
  5. Open the account and accept the transactions. Quicken may add them automatically, depending on your download preferences.

The same import article also lists File, File Import, Quicken Transfer Format (.QFX) File, then Browse and Open. Web Connect troubleshooting lists File, File Import, Web Connect (.QFX) File. Use whichever of those labels your version shows.

Quicken for Mac

Downloading transactions (Quicken for Mac) says:

  1. Back up the data file.
  2. Go to File, Import, Bank or Brokerage File (OFX, QFX).
  3. Select the file and open it.
  4. On Choose Your Accounts, pick the account.
  5. Review the register.

The Windows troubleshooting article gives the Mac path as File, Import, Bank or Brokerage File (OFX, QFX) as well.

What will not import as Web Connect

  • Quicken says only a QFX file downloads transactions this way. QIF files will not work with Web Connect.
  • If the bank no longer supports Web Connect, Quicken says the file cannot be authorized when you import it. Error CC-885 is covered in this guide.
  • Quicken's CSV import is a different feature. The file must use Quicken's own column order (Date, Payee, FI Payee, Amount, Debit/Credit, Category, Account, and optional Tag, Memo, Chknum). A bank CSV does not match that layout, and Quicken says CSV import does not check for transactions you already have.

QuickBooks Desktop needs a .qbo file instead: import into QuickBooks Desktop. QuickBooks Online can take QFX, QBO, or CSV: upload in QuickBooks Online.

FAQ

The bank only gave me a CSV or a QIF file.

Convert the CSV or Excel file to QFX, then use the Web Connect import above. Do not rename the CSV to .qfx.

Quicken created a second account.

On the import prompt, link the file to the existing account instead of creating a new one. Quicken's Windows article calls this Link.

Do I need an active Quicken subscription?

Quicken's troubleshooting page says Web Connect files need online services to validate the file. An expired subscription or an unsupported Quicken version cannot import Web Connect.
