Private by design

Bank statements are some of the most sensitive files you have. Most online converters ask you to upload them to their servers. Rowbridge doesn't: the page loads once, and your file is read and converted by JavaScript in your own browser. You can check this yourself. Open your browser's developer tools, watch the Network tab, and convert a file. No request carries your data. Apart from anonymous usage counts (like "a file was converted", never its contents), the page talks to no other server, and a strict security policy enforces that in your browser.

Questions

Why can't I just import the CSV?

QuickBooks Desktop has no import for bank-statement CSV files. Its bank import is Web Connect (.qbo). Quicken imports QFX best, and its CSV import is limited or missing depending on the version. QuickBooks Online does accept CSV, but a .qbo file skips the column-mapping step and gives each transaction a unique ID.

Which banks does it work with?

Any bank that exports CSV or Excel. Headers in English and the most common German, French, Spanish and Dutch terms are recognised. Files without a header row work too. You can always set each column by hand.

My bank has separate Debit and Credit columns.

That's supported. Map both and we combine them into one signed amount, with money out as negative. "Paid in / Paid out", "Withdrawals / Deposits" and DR/CR indicator columns work too.

Will re-importing the same file create duplicates?

Each transaction gets a stable ID (FITID) built from its date, amount, description and account number. Converting the same rows again produces the same IDs, so QuickBooks and Quicken can recognise transactions they've already seen. Keep the account number the same between imports.

What does the free version include?

Everything, for files of up to 30 transactions. Larger files convert their first 30 transactions. Pro (coming soon) removes the limit and adds batch conversion and saved column mappings. See pricing.

Do you support PDF statements?

Not yet. Download CSV or Excel from your online banking instead. PDFs need text recognition, and doing that well usually means uploading the file, which we want to avoid.
