How to convert a bank CSV to QBO for QuickBooks Desktop

QuickBooks Desktop (Pro, Premier, Enterprise and Accountant) has no import for bank-statement CSV files. Its built-in way to bring in bank transactions is Web Connect: a .qbo file, which is an OFX file with an Intuit bank identifier added. If your bank only offers CSV or Excel, or you need older history than its download allows, convert the export to .qbo first.

1. Export the transactions from your bank

In online banking, open the account, choose the date range and download the transactions as CSV (sometimes labelled "Excel", "Spreadsheet" or "Comma delimited"). An .xlsx or .xls download works too. Avoid PDF: it has to be re-read and can introduce errors.

2. Convert it to .qbo

  1. Open the converter and drop the file in.
  2. Check the detected columns: Date, Description, and either one signed Amount column or separate Debit/Credit columns.
  3. Check the date format. 03/04/2026 means 4 March in the US and 3 April in most other countries. The preview shows the dates as YYYY-MM-DD so you can confirm.
  4. Choose QBO, pick the account type (checking, savings or credit card) and enter your account number. QuickBooks uses it to remember which account the file belongs to, so keep it the same every month.
  5. Download the .qbo file.

3. Import it into QuickBooks Desktop

  1. Back up your company file first (File › Back Up Company), especially the first time.
  2. Go to File › Utilities › Import › Web Connect Files and pick the .qbo file. Double-clicking the file also works when QuickBooks is open.
  3. When asked, choose Use an existing QuickBooks account and pick the bank or card account.
  4. Open Banking › Bank Feeds › Bank Feeds Center and review and add the downloaded transactions.

About the bank ID (INTU.BID)

Every .qbo file names a financial institution through an INTU.BID code. QuickBooks Desktop checks this code against Intuit's list of banks that support Web Connect. If the code isn't on the list, you'll see an error like "QuickBooks is unable to verify the Financial Institution information for this download."

The converter uses 3000 by default. Most converters use this code and QuickBooks generally accepts it. The code only labels the file. It doesn't connect to any bank, and your transactions land in whichever QuickBooks account you link the file to. If your version rejects it, try the code of another bank that supports Web Connect.

Common problems

  • Dates are a month off, or some rows are missing. The date format was wrong. Switch between DD/MM and MM/DD and convert again.
  • Spending shows as deposits. Some exports, especially credit card ones, show charges as positive numbers. Tick Flip signs.
  • Payee names are cut off. Web Connect allows 32 characters for the payee name. The converter puts the full description in the memo.
  • Duplicates after importing twice. Use the same account number each time. The converter gives each transaction a stable ID, so QuickBooks can recognise ones it has already downloaded.
  • "This account is set up for Direct Connect / Bank Feeds." If the QuickBooks account is already connected to a bank feed under a different bank, deactivate the feed for that account (Edit Account › Bank Feed Settings) or import into a new account.
