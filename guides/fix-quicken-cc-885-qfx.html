Quicken error CC-885: keep importing with a QFX file

Quicken shows CC-885 when it can't update or import an account because Web Connect / Express Web Connect support for your financial institution has been temporarily or permanently discontinued (see Quicken's support article). It usually happens after a bank stops supporting Quicken downloads, changes its connection method, or merges with another bank. You'll often see it when you import a .qfx file you downloaded from the bank.

First, the quick checks

  1. Wait 24 hours and try again. Quicken says the outage is sometimes temporary.
  2. Check whether your bank now offers a different connection in Quicken (for example Express Web Connect+). If it does and you're happy with it, reconnecting the account may be enough.
  3. If downloads for your bank have really stopped, or you need transactions the connection doesn't provide, read on.

Keep importing: CSV → QFX

Almost every bank still lets you download transactions as CSV or Excel. You can turn that export into a QFX file that names a financial institution Quicken accepts, then import it into your existing account.

Convert your file now: open the converter. It runs in your browser, your statement is never uploaded, and it's free up to 30 transactions per file.
  1. Download your transactions from online banking as CSV (or .xlsx/.xls).
  2. Open the converter, drop the file in and check the columns, date format and preview.
  3. Choose QFX, the account type, and the account number. Use the same number every time so Quicken links future imports to the same account.
  4. Download the .qfx file.
  5. Quicken for Windows: File › File Import › Web Connect (.QFX) File. Quicken for Mac: File › Import › Bank or Brokerage File (OFX, QFX).
  6. When Quicken asks, link it to your existing account rather than creating a new one, then accept the transactions.

If Quicken still refuses the file

  • Account is still set up for the discontinued connection. In Quicken for Windows open the account, then Account Details › Online Services and Deactivate online services. Then import the QFX and link it to the account.
  • Bank ID not accepted. Quicken checks the bank ID (INTU.BID) inside the file against the institutions that support Web Connect. If yours isn't accepted, change the Intuit bank ID field in the converter to another participating bank's ID.
  • Wrong signs or dates. Use Flip signs for card exports that show charges as positive, and check DD/MM vs MM/DD.
  • Back up first. Make a backup (File › Backup and Restore) before your first import.
